# 连续模拟盘说明

连续模拟盘用于验证策略在多交易日连续运行时的账户表现。它比单次模拟更接近日常运行流程。

## 运行方式

使用多股票历史日线 CSV：

```bash
go run ./cmd/autogupiao -mode paper -input data/bars/multi.csv -cash 10000 -top 1 -min-score 60
```

如果要允许每天买入多个候选：

```bash
go run ./cmd/autogupiao -mode paper -input data/bars/multi.csv -cash 10000 -top 3 -min-score 60 -allow-multiple-buys
```

卖出价默认使用次日开盘价，可以切换为收盘价：

```bash
go run ./cmd/autogupiao -mode paper -input data/bars/multi.csv -cash 10000 -top 1 -min-score 60 -paper-sell-price close
```

## 输入字段

CSV 字段与历史回测一致：

```text
date,code,open,high,low,close,prev_close,change,change_pct,volume,amount
```

同一个文件可以包含多只股票、多天数据。系统会按日期分组，每个交易日执行：

1. 先卖出前一交易日持仓。
2. 再用当日收盘价生成候选并模拟买入。
3. 记录当日现金、持仓市值、总权益和日收益。

## 输出字段

输出 JSON 包含：

- `initial_cash`
- `final_equity`
- `total_return_pct`
- `max_drawdown_pct`
- `days`
- `trades`
- `wins`
- `losses`
- `win_rate_pct`
- `profit_factor`
- `max_consecutive_loss`
- `daily_equity`
- `trades_list`

## 当前限制

- 当前仍使用日线近似交易，不是分钟线撮合。
- 买入价使用当日收盘价近似 14:00 后买入。
- 卖出价默认使用次日开盘价，可通过 `-paper-sell-price close` 改为次日收盘价。
- 最后一个交易日不会新增买入，因为没有下一交易日可卖出。
