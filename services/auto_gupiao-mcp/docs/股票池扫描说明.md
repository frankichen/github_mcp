# 股票池扫描说明

本系统支持两种服务器观察盘股票池模式：

## custom

手工指定股票代码，适合小范围验证。

```json
"data": {
  "source": "akshare",
  "universe": "custom",
  "codes": ["000001", "600000", "601288"],
  "codes_file": "",
  "start_date": "20250101",
  "end_date": "",
  "bars_file": "data/bars/batch_akshare.csv"
}
```

## all_a

从 AKShare 实时快照自动获取 A 股股票池，再按基础条件过滤，适合服务器观察盘。

```json
"data": {
  "source": "akshare",
  "universe": "all_a",
  "codes": [],
  "codes_file": "",
  "start_date": "20250101",
  "end_date": "",
  "bars_file": "data/bars/batch_akshare.csv",
  "universe_limit": 30,
  "min_universe_price": 2,
  "max_universe_price": 80,
  "min_universe_amount": 100000000
}
```

过滤规则：

- 排除 ST、停牌、涨跌停和无价格股票。
- 排除价格低于 `min_universe_price` 的股票。
- 排除价格高于 `max_universe_price` 的股票。
- 排除成交额低于 `min_universe_amount` 的股票。
- 剩余股票按成交额从高到低排序，取前 `universe_limit` 只。

## 推荐起步参数

第一次不要直接扫太大股票池，建议：

```json
"universe_limit": 30,
"min_universe_price": 2,
"max_universe_price": 80,
"min_universe_amount": 100000000
```

观察稳定后可以逐步扩大：

```json
"universe_limit": 50
```

再稳定后再考虑：

```json
"universe_limit": 100
```

注意：`all_a` 会先拉实时快照，再逐只拉历史日线。股票池越大，首次运行越慢。AKShare 上游偶发超时或 SSL 问题时，建议先保持较小 `universe_limit`。

## 和 strict_entry 的关系

`universe` 决定“从哪些股票里找”；`strict_entry` 决定“是否允许买入”。

服务器观察盘建议同时使用：

```json
"strategy": {
  "top": 1,
  "min_score": 90,
  "strict_entry": true,
  "min_trade_amount": 3000,
  "cooldown_days": 10
}
```

这样系统会宁可空仓，也不买弱信号。
