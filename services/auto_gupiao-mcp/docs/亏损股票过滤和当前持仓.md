# 亏损股票过滤和当前持仓展示

本功能用于降低同一只股票反复拖累观察盘的风险，并让报告展示历史回放末尾仍未平仓的模拟持仓。

## 当前未平仓持仓

日报 Markdown 会新增：

```text
当前未平仓持仓
```

展示字段包括：

- 代码
- 买入日
- 当前日
- 股数
- 买入价
- 当前价
- 买入成本
- 估算净值
- 浮动盈亏
- 浮动收益率
- 持有天数
- 风险等级

说明：这些都是历史回放末尾的模拟持仓，不是真实账户持仓。

## 亏损股票过滤

配置：

```json
"strategy": {
  "poor_performer_filter": true,
  "poor_performer_min_trades": 2,
  "poor_performer_max_net_profit": -300
}
```

含义：

- `poor_performer_filter`：是否启用亏损股票过滤。
- `poor_performer_min_trades`：同一只股票至少完成多少笔已平仓模拟交易后才评估。
- `poor_performer_max_net_profit`：同一只股票历史已发生模拟交易累计净利润低于或等于该值时，后续回放中临时过滤。

默认规则：

```text
同一只股票至少 2 笔已平仓模拟交易，且累计净利润 <= -300，则后续回放不再新增该股票的模拟仓位。
```

## 不偷看未来

过滤只使用“当时已经发生的已平仓模拟交易”。

例如回放运行到 2026-03-01 时，只能使用 2026-03-01 之前已经完成的交易记录，不会使用未来日期的亏损结果。

## 目的

这个过滤器不是为了让回测曲线变漂亮，而是为了降低这类风险：

- 同一只股票连续触发 stop_loss。
- 同一只股票累计归因为明显负值。
- 观察盘反复进入历史上已经表现很差的标的。

## 调参建议

更保守：

```json
"poor_performer_min_trades": 1,
"poor_performer_max_net_profit": -100
```

更宽松：

```json
"poor_performer_min_trades": 3,
"poor_performer_max_net_profit": -500
```

当前建议先使用默认值，不要频繁调参，继续观察 5 到 10 个交易日。
