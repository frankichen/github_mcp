# 开发路线图

## 第一阶段：MVP 原型

目标：完成可以本地运行的规则选股原型。

- [x] 初始化 Go Modules。
- [x] 建立股票快照、候选股、交易成本模型。
- [x] 支持 CSV 行情输入。
- [x] 实现规则评分和候选股排序。
- [x] 支持 1 万元资金和 100 股整手约束。
- [x] 输出 JSON 候选股。
- [x] 增加基础单元测试。

## 第二阶段：数据源接入

目标：从示例 CSV 过渡到真实数据源。

- [ ] 定义 `MarketDataProvider` 接口。
- [ ] 接入 A 股实时行情源。
- [ ] 接入历史 K 线数据。
- [ ] 接入股票基础信息、停牌、ST、涨跌停状态。
- [ ] 增加数据质量校验。
- [ ] 增加本地缓存。

## 第三阶段：回测引擎

目标：用历史数据验证策略有效性。

- [ ] 实现历史交易日历。
- [ ] 实现撮合模拟。
- [ ] 实现买入、卖出、手续费、滑点计算。
- [ ] 统计胜率、收益率、最大回撤、盈亏比。
- [ ] 支持参数批量回测。
- [ ] 输出回测报告。

## 第四阶段：模拟盘

目标：使用实时行情和虚拟资金验证交易闭环。

- [ ] 实现模拟账户。
- [ ] 实现模拟委托和成交。
- [ ] 实现持仓、资金、成交记录。
- [ ] 接入 14:00 后选股任务。
- [ ] 接入次日 10:00 卖出任务。
- [ ] 输出每日模拟交易报告。

## 第五阶段：实盘预研

目标：在可控风险下评估真实交易可行性。

- [ ] 抽象 Broker 接口。
- [ ] 接入券商查询接口。
- [ ] 接入券商下单接口。
- [ ] 增加人工确认开关。
- [ ] 增加熔断和只观察模式。
- [ ] 增加实盘审计日志。

## 第六阶段：策略增强

目标：从简单规则打分升级到更稳健的策略组合。

- [ ] 增加行业和概念板块强度。
- [ ] 增加市场环境过滤器。
- [ ] 增加资金流和成交额排名。
- [ ] 增加多策略投票机制。
- [ ] 增加机器学习模型适配接口。
- [ ] 增加策略表现漂移监控。
