# 观察备注和人工复核

本功能用于记录每天观察盘结果的人工作业状态。

它不是交易接口，也不会连接同花顺、券商客户端或真实资金账户。

## 功能

在 dashboard 的单次运行详情页，会出现“观察备注”区域，可以记录：

- 待查看
- 已查看
- 跳过
- 需要复盘
- 备注内容
- 更新时间

这些信息会写入 SQLite 数据库：

```text
data/autogupiao.db
```

## 使用场景

例如：

- 今天的观察盘已经人工看过。
- 今天虽然信号好，但决定跳过。
- 今天风险较高，需要后续复盘。
- 已经在同花顺或券商软件里手工查看过对应股票。

## 安全边界

本功能只做记录，不做任何真实账户操作。

系统不会：

- 连接券商账户
- 连接同花顺客户端
- 自动提交委托
- 自动买入或卖出

以后如果要接真实交易通道，应在这个人工复核流程稳定后，再单独增加明确的券商适配器、强制风控、人工确认和审计日志。
