# 硬风控过滤和过滤统计

本功能用于降低观察盘反复进入历史上明显拖累标的的风险。

## 新增规则

### 1. 单笔大亏过滤

配置：

```json
"single_loss_filter": true,
"single_loss_max_net_profit": -300,
"single_loss_max_return_pct": -5
```

含义：

同一只股票只要曾经出现过已平仓模拟交易，并且满足以下任一条件：

- 卖出原因是 `stop_loss` 且净利润 <= -300
- 卖出原因是 `stop_loss` 且收益率 <= -5%

则后续历史回放中会过滤该股票。

### 2. stop_loss 后长冷却

配置：

```json
"stop_loss_cooldown_days": 30
```

含义：

当某只股票触发 `stop_loss` 后，后续至少冷却 30 个交易日。

普通亏损仍使用：

```json
"cooldown_days": 10
```

### 3. 累计亏损过滤

配置：

```json
"poor_performer_filter": true,
"poor_performer_min_trades": 2,
"poor_performer_max_net_profit": -300
```

含义：

同一只股票至少 2 笔已平仓模拟交易，且累计净利润 <= -300，则后续历史回放中会过滤该股票。

## 不偷看未来

所有过滤规则只使用“当前回放日期之前已经完成平仓的模拟交易”。

例如回放运行到 2026-03-01，只能使用 2026-03-01 之前已经完成的交易记录，不能使用未来交易结果。

## 过滤生效统计

日报 Markdown 会新增：

```text
过滤生效统计
```

展示字段：

- 代码
- 过滤原因
- 次数
- 最近日期

过滤原因包括：

- 单笔大亏过滤
- 止损后冷却
- 累计亏损过滤
- 亏损后冷却

## 默认建议

当前建议使用：

```json
"cooldown_days": 10,
"stop_loss_cooldown_days": 30,
"poor_performer_filter": true,
"poor_performer_min_trades": 2,
"poor_performer_max_net_profit": -300,
"single_loss_filter": true,
"single_loss_max_net_profit": -300,
"single_loss_max_return_pct": -5
```

如果过滤过强导致长期无候选，可以先调宽：

```json
"single_loss_max_net_profit": -500,
"single_loss_max_return_pct": -8,
"stop_loss_cooldown_days": 20
```

## 安全边界

本功能只影响历史回放观察盘，不连接券商，不连接同花顺，不执行真实交易。
