# 观察盘数据库和页面

系统支持把每天的观察盘结果写入轻量 SQLite 数据库，并启动一个简单 Web 页面查看投资观察状态。

## SQLite 驱动

项目使用 `modernc.org/sqlite`，这是纯 Go SQLite 驱动，不依赖 CGO，不需要 gcc，也不使用 `mattn/go-sqlite3`。

数据库默认路径：

```json
"database": {
  "enabled": true,
  "path": "data/autogupiao.db"
}
```

每天 `autogupiao-server` 运行完成后，会写入：

- 每日运行汇总
- 每日权益曲线
- 交易明细
- 按股票归因
- 按卖出原因归因
- 报告文件链接

## 页面服务

新增命令：

```bash
./bin/autogupiao-dashboard -config configs/server.json
```

默认监听：

```json
"dashboard": {
  "address": ":8080",
  "username": "admin",
  "password": "请改成强密码"
}
```

如果配置了用户名或密码，页面会启用 Basic Auth。

页面包含：

- 最近 60 次运行记录
- 每次运行的收益率、最大回撤、交易次数、胜率、盈利因子
- 单次运行详情
- 按股票归因
- 按卖出原因归因
- 权益曲线明细
- 交易明细
- Markdown / trades CSV / equity CSV 链接

## 发布建议

构建：

```bash
go build -o bin/autogupiao-server ./cmd/autogupiao-server
go build -o bin/autogupiao-dashboard ./cmd/autogupiao-dashboard
```

每日任务继续运行：

```bash
./bin/autogupiao-server -config configs/server.json
```

页面常驻运行：

```bash
./bin/autogupiao-dashboard -config configs/server.json
```

如果使用 Docker 或 systemd，请让 dashboard 进程常驻。

## 安全建议

- dashboard 不要裸奔公网。
- 至少设置 `dashboard.username` 和 `dashboard.password`。
- 更推荐通过 Nginx/Cloudflare Access 再加一层访问控制。
- SQLite 文件建议定期备份：`data/autogupiao.db`。
