# 稳定运行说明

本文档说明当前系统在进入连续模拟盘前需要关注的两项能力：数据质量校验和每日任务计划。

## 数据质量校验

CLI 已在以下模式接入数据质量校验：

- `select`
- `backtest`
- `simulate`
- `fetch-bars`

默认行为：

- 发现 error 时终止运行。
- 发现 warning 时把质量报告输出到 stderr，但主流程继续。

如果希望 warning 也导致运行失败，可以增加：

```bash
go run ./cmd/autogupiao -mode select -source csv -input examples/sample_quotes.csv -strict-quality
```

常见校验项：

- 股票代码是否为空。
- 日期是否为空。
- 价格是否大于 0。
- high 是否小于 low。
- open / close 是否明显超出 high / low。
- 同一 code + date 是否重复。
- AKShare 增强模式下技术指标缺失比例是否过高。

## 每日任务计划

系统已支持生成日内任务计划：

```bash
go run ./cmd/autogupiao -mode plan -trade-date 20260519
```

默认输出包括：

- 14:00 盘中选股。
- 14:05 模拟买入。
- 次日 10:00 模拟卖出。
- 次日 15:30 生成报告。

可以指定下一交易日和时间：

```bash
go run ./cmd/autogupiao -mode plan -trade-date 20260519 -next-trade-date 20260520 -select-time 13:55 -buy-time 14:05 -sell-time 10:00 -report-time 15:30
```

## 当前限制

当前 `plan` 只负责生成计划，不会后台常驻执行任务。后续可以在此基础上继续开发：

- 本地定时器。
- 模拟盘账户持久化。
- 连续多交易日模拟盘。
- 日报生成。
