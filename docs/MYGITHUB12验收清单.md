# MyGithut12 验收清单

## 1. 版本与发现

- [ ] capability 名称精确等于 `MyGithut12`。
- [ ] 版本精确等于 `12.0.0`。
- [ ] Build SHA 为部署源码的完整 40 位小写 Commit。
- [ ] Connector 实际显示 MyGithut12。
- [ ] 客户端发现 154 个唯一工具。
- [ ] 36 个新增工具名称与规划总览一致。
- [ ] 原 118 个工具仍可发现且必填参数无破坏性变化。
- [ ] Manifest 与运行时 `list_tools` 完全一致。

## 2. 精确 Commit 与不可变索引

- [ ] 每个新读取、搜索和分析工具返回 resolved Commit 和 Tree。
- [ ] 文件和片段结果返回 Blob 和精确行范围。
- [ ] ref/Commit、Commit/Tree 或 Blob 不一致时失败关闭。
- [ ] 已完成索引只读，分支移动不会修改旧索引。
- [ ] 同一 Commit 重复查询结果顺序稳定，游标可复现。

## 3. 全量、增量和构建任务

- [ ] 支持 auto、incremental 和 full。
- [ ] 相同目标 Commit 的并发构建只生成一个有效任务。
- [ ] 新分支与 main 指向相同 Commit 时立即复用索引。
- [ ] 小范围提交复用未变化 Blob，只重建变化和受影响关系。
- [ ] Manifest 返回 base、reused、changed 和 reindexed 统计。
- [ ] wait 工具最长 55 秒并按状态/步骤/Revision 变化返回。
- [ ] cancel 不删除已完成索引。
- [ ] 失败、重试、僵尸回收、配额、Pin 和过期清理有效。

## 4. 多聊天窗口工作区

- [ ] 三个窗口可创建三个唯一工作区和分支。
- [ ] 每个工作区返回独立 ID、Revision、HEAD、Tree、租约和索引。
- [ ] 不存在进程级共享 current branch/current repository。
- [ ] 不同分支并发读写互不串线。
- [ ] 同一分支只能有一个有效独占写租约。
- [ ] 同一分支双写至少一个请求返回稳定冲突，不发生覆盖。
- [ ] 租约续期必须校验 workspace Revision。
- [ ] 外部推送后工作区标记 drifted，写入被阻止。
- [ ] refresh 后才可基于新 HEAD 继续。
- [ ] close 释放租约和 Pin，但不自动删除分支、PR 或代码。

## 5. 范围、重叠和同步规划

- [ ] 可声明路径、符号、API、表、迁移、事件和配置范围。
- [ ] overlap 同时比较声明范围和实际 Commit 变化。
- [ ] 文件、符号、契约和迁移重叠均返回证据。
- [ ] 冲突等级可稳定复现。
- [ ] sync plan 正确比较基础 Commit、当前基础分支和工作区 HEAD。
- [ ] sync plan 不执行 rebase、merge 或 force push。

## 6. 树、文件、文本和语义搜索

- [ ] 树工具处理路径、深度、Glob、数量和游标。
- [ ] 文件搜索不混入内容结果。
- [ ] 批量读取逐文件返回成功或失败。
- [ ] 文件数和总字节超限返回稳定错误。
- [ ] 文本搜索支持普通文本、大小写、路径、上下文和受限正则。
- [ ] 高风险正则被拒绝或超时终止。
- [ ] 语义结果绑定路径、Blob、行范围和评分。
- [ ] 语义结果明确标记非权威，不能冒充符号关系。

## 7. 符号和语言智能

- [ ] 五种首批语言建立符号目录。
- [ ] 同名符号拥有不同稳定 ID。
- [ ] 定义支持 symbol_id 和文件位置。
- [ ] 引用不把文本同名误报为可靠引用。
- [ ] 调用层级支持 callers、callees 和 both。
- [ ] 循环调用不会无限展开。
- [ ] 实现和类型层级具有语言服务证据。
- [ ] 诊断不能接受任意命令。
- [ ] 符号历史返回创建、变化、重命名和删除 Commit。
- [ ] 不支持语言和适配器故障返回稳定 unavailable。

## 8. 依赖、指令和上下文

- [ ] 依赖图区分 import、调用、实现和生成关系。
- [ ] AGENTS、CLAUDE、CONTRIBUTING 和 README 按目标路径解析。
- [ ] 指令冲突返回来源和优先级。
- [ ] 仓库上下文包每项都有选择理由。
- [ ] 变化上下文包包含变化、调用方、测试、契约和文档。
- [ ] 所有上下文严格遵守文件数和总字节。
- [ ] omitted 项和原因完整返回。

## 9. 变化、补丁、测试和契约

- [ ] Commit 影响分析覆盖符号、模块、API、数据、配置和测试。
- [ ] 分析不完整时明确返回 incomplete 和缺失分析器。
- [ ] 补丁在临时派生快照应用，不写 GitHub。
- [ ] 补丁基础 Commit、Blob 或上下文错误时失败。
- [ ] 补丁结果包含诊断、影响、测试和契约变化。
- [ ] 受影响测试区分 direct、package、integration 和 regression。
- [ ] 每个测试候选有证据和置信等级。
- [ ] OpenAPI、迁移、事件、配置、权限、CLI 和公共符号契约可检测。
- [ ] 契约变化区分 breaking、compatible 和 unknown。

## 10. 安全

- [ ] 未授权仓库全部拒绝。
- [ ] 参数不能注入任意 Git URL、主机、本地路径、Shell、SQL 或可执行参数。
- [ ] 路径穿越、绝对路径、控制字符和符号链接逃逸被拒绝。
- [ ] Secret、私钥、证书、Token、二进制、依赖和构建目录默认不索引。
- [ ] 日志和 Metrics 不含文件全文、凭据或 Authorization。
- [ ] 内部索引认证与 GitHub Token 分离。
- [ ] 正则、语义、图、历史、补丁、CPU、内存、磁盘和并发有硬限制。
- [ ] 工作区 ID、租约和事件不泄露凭据。

## 11. 性能与稳定性

在约 50 MiB 的 `frankichen/sxt` 或等价仓库热状态：

- [ ] 索引状态、路径搜索和相同 Commit 复用 P95 小于 1 秒。
- [ ] 文本、语义和符号搜索 P95 小于 3 秒。
- [ ] 定义、引用、实现和类型层级 P95 小于 5 秒。
- [ ] 上下文、影响和契约分析 P95 小于 10 秒。
- [ ] 小范围提交增量索引 P95 目标小于 15 秒。
- [ ] 查询或构建超时不会拖垮 Controller。
- [ ] 索引或工作区服务停止时，原 118 个工具仍正常。
- [ ] 多窗口并发下没有跨工作区数据串线。

## 12. 测试与发布证据

- [ ] pytest、Ruff 和现有 CI 全部通过。
- [ ] 36 个 MCP 契约测试和 24 个内部接口契约测试通过。
- [ ] 多语言 Fixture、工作区并发和索引一致性测试通过。
- [ ] `github_mcp` 和 `sxt` 冒烟测试通过。
- [ ] 原 118 个工具全量回归通过。
- [ ] 镜像版本、Build SHA 和源码 Commit 一致。
- [ ] 灰度、回滚、工作区数据库迁移和灾难恢复经过演练。

## 13. 验收结论

只有客户端真实发现 MyGithut12 和 154 个工具、精确 SHA 与不可变索引成立、多窗口工作区隔离和租约正确、36 个新工具全部可用、安全与回归通过，才能签署发布验收。服务端存在代码但客户端不可发现，或任何分析工具使用旧索引冒充当前 Commit，验收必须失败。
